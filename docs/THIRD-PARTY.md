# Calling-code data

The bundled ISO-region → telephone calling-code maps were generated from
[python-phonenumbers](https://github.com/daviddrysdale/python-phonenumbers)
version 9.0.41, a port of Google's libphonenumber. The data is used offline;
no phone numbers are sent to a service.

See [Apache 2.0 license](licenses/phonenumbers-LICENSE.txt). Country/currency
names and currency precision are supplied by the operating system's locale data.
